Panduan & Teori Konfigurasi IP Print Server

Mengapa Print Server Menggunakan IP Statis?

Print Server bertindak sebagai layanan bersama (shared resource) di dalam jaringan LAN. Jika menggunakan DHCP (IP Dinamis), IP pencetak dapat berubah-ubah setiap kali dinyalakan ulang. Hal ini menyebabkan komputer klien gagal mencetak dokumen karena kehilangan alamat tujuan. Oleh karena itu, Print Server WAJIB dikonfigurasi dengan IP Statis.

Aturan Konfigurasi IP pada Subnet /24:

  • IP Address: Harus berada dalam rentang subnet lokal yang sama (192.168.1.2 - 192.168.1.254) dan TIDAK BOLEH sama dengan IP host lain (IP Router 192.168.1.1 atau PC-01 192.168.1.10).
  • Subnet Mask: Menentukan batas jaringan. Untuk prefix /24, nilainya adalah 255.255.255.0.
  • Default Gateway: Alamat IP interface Router lokal (192.168.1.1) yang menjembatani komunikasi keluar dari jaringan LAN.

Langkah Kerja Praktikum:

  1. Tarik Kabel UTP dari rak alat di sebelah kiri menuju perangkat Print Server. (Di HP/tablet: klik kabel, lalu klik Print Server.)
  2. Klik tombol Buka Solver IP pada Misi 2 untuk menyelesaikan teka-teki penentuan IP Statis.
  3. Buka Control Panel Print Server lalu masukkan parameter IP Statis yang valid.
  4. Buka Terminal PC-01 lalu jalankan perintah ping 192.168.1.200 dan print test.
